# Working with the session

The course reader and the session can communicate in both directions.

| Direction | Example |
| --- | --- |
| You to the session | Select a passage, stage it in the composer, then write and send a question |
| Session to the reader | Open a page, follow a navigation link, or refresh it |

**Ask in chat** stages the complete selected text as a composer attachment.
It does not send a message. The reply appears in chat after you write and send
your question yourself. Merely navigating or refreshing does not stage content.
