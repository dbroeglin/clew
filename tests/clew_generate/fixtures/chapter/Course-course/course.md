# Geometric limits

> [!theorem] Geometric limit result
>
> If $|q|<1$, then $q^n$ tends to zero.
>
> [PDF p. 1](course.pdf#page=1)

^theorem

## Bounds

# Subsequences

Every subsequence of a convergent sequence has the same limit.
