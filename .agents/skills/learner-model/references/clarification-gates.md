# Learning memory v1: when to clarify

Use the [small storage contract](learner-model-spec.md). Block only the affected
operation, not independent course lookup. Do not ask questions merely to fill
optional metadata or create schema-shaped records.

| Situation | Behavior |
| --- | --- |
| Unknown vault or ambiguous selected source | Ask for the explicit root/target. Never assume the clone is a vault or scan everything. |
| Path alone | Ask the learning goal; create nothing. |
| Bare continue, recall or inspection | Read bounded relevant memory and answer; no model/artifact writes. |
| Genuine goal/preference without domain metadata | Record the dated learner statement directly in the summary. No taxonomy or session required. |
| Meaningful attempted work | Retain it once in a useful dated session or substantial-work artifact; link it, don't build a graph. |
| Old profile/index/graph, advanced layout, missing/unknown/conflicting marker, unrelated reserved paths | Ask for explicit migration/ownership choice; preserve files, no automatic adoption. Advanced designs are not supported alternate runtimes. |
| Missing support or contradictory memory | Explain the affected limitation; ask before relying on or correcting an uncertain claim. |
| Same labels across topics/courses | Preserve source context; ask only if reuse/selection depends on unresolved identity. |
| Current-only presentation request | Apply now; do not infer a standing preference, scope or benefit. |
| Correction versus subsequent answer | Correct authorized recording/feedback mistakes directly; preserve the actual earlier answer unless it was explicitly misrecorded. |
| Ambiguous forget or shared work | Ask whether to stop using which item or delete which local content; preserve unrelated/shared material. |
| Concrete local deletion | Explain consequences and obtain explicit scoped confirmation under host rules before acting. Hosted context/backups are not erased. |
| Concurrent change or partial failure | Stop, state exactly what persisted, and reconcile; no overwrite or transaction claim. |

No numerical policy, due queue, empty adaptation record, observation ledger,
change chain or tombstone system is required. No gate authorizes bulk uploads,
passive telemetry, teacher access or fabricated learning.
